## 合规红线（每条视频、每条文案都过一遍）

1. **说明是校准估分，不是官方成绩**。视频结尾或评论区置顶要有这句。
2. **不声称与 IELTS / British Council / IDP / Cambridge / ETS 有任何隶属或认可关系**；画面里不出现这些机构的 logo。
3. **不出现官方评分描述符原文**，只讲操作化后的做法。
4. 不说「独家」「别处拿不到」：开源部分本来免费，卖的是整理、说明和更新。
5. 不用「最」「第一」「国家级」等绝对化用语；不贬低具体竞品。
6. 价格与海报常量一致；「限时」要有真实截止。
7. 引用他人视频只做对比，注明来源；BGM 用平台曲库或无版权音乐。
8. AI 生成画面不得模仿真实机构界面或真题。
9. **「作文不上传 / 本地处理」只能说 Claude Code 版**。上传版的作文会发给用户选择的聊天机器人，两种用法的表述不要混用。
10. 效果截图全部来自 Claude Code 版的真实运行；带 Word 批注的画面要标「Claude Code 版」，不要拿来代表上传版。
