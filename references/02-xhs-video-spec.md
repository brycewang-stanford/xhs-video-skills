# 小红书视频规格（2026-09 整理）

数字来自公开运营资料和上传页的实际行为，不是平台官方硬性文档。上传前若平台改版，以上传页提示为准。

## 成片

| 项 | 建议值 | 说明 |
|---|---|---|
| 比例 / 分辨率 | **9:16 · 1080×1920**（首选）；3:4 · 1080×1440（备选） | 9:16 在信息流占屏最大；3:4 与图文封面一致 |
| 帧率 | 30fps（屏录 / 口播够用；运动镜头 60） | `xhs_export.py --fps 30` |
| 编码 | H.264 High、yuv420p、AAC 48kHz 192k、`+faststart` | `xhs_export.py` 默认 |
| 码率 | CRF 19，约 8–12 Mbps @1080×1920 | 平台会二压，源片高一点更抗压 |
| 时长 | **带货 20–45 秒**；平台上限 15 分钟 | 前 3 秒决定完播；超过 60 秒要有强理由 |
| 文件 | ≤ 5GB，MP4 / MOV | 通常 20–80MB |
| 响度 | -16 LUFS，峰值 -1.5 dBTP | `loudnorm` 已内置 |

## 封面

- 3:4 竖版 **1242×1656**（或 1080×1440），JPG / PNG：`cover_frames.py --pick <秒> --aspect 3:4`
- 封面文案 ≤ 12 字，宋体大字 + 商品主色，和海报封面同一体系（见 06）
- 封面是独立图片，不要指望视频首帧自动好看；候选帧网格 `contact.jpg` 只是选画面用

## 安全区（1080×1920 画布，按手机端 UI 估算）

| 区域 | 尺寸 | 会被什么遮住 |
|---|---|---|
| 顶部 | 约 200px | 状态栏、返回、分享 |
| 底部 | 约 420px | 标题、正文、话题、互动栏、进度条 |
| 右侧 | 约 180px（下半屏） | 头像、点赞、收藏、评论按钮列 |

- 关键文字放中央 60% 区域；字幕基线放在**距底 600–700px**（`burn_subs.py --bottom 640`）
- 屏录时把终端 / 窗口字号调大（≥ 18pt），窗口比例接近 9:16，避免整屏缩小后看不清

## 字幕

- 一句一屏，**≤ 14 个汉字**，超过就拆
- 字号 ≥ 56px @1080 宽（默认 64）；白字 + 深色描边 3px（`--style clean`），或米白底黑字盒（`--style box`）
- 字体：PingFang SC / Hiragino Sans GB（正文），Songti SC（标题）
- 关键词（价格、数字、「改版」）用主色或黄标突出，一屏最多 1 处

## 命名与归档

- 成片：`<商品>-<渠道>-<YYYYMMDD>-v<N>.mp4`，例 `托福-claudecode-20260905-v1.mp4`
- 封面：`<商品>-cover-<YYYYMMDD>.png`
- 归档到 `宣传海报-汇总/<商品>-海报/视频/`，`脚本.md`、`文案.md` 放一起
