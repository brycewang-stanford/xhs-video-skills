# 发布前检查清单

全部打勾才算完成。任何一项没过，在报告里写明原因，不要宣称完成。

## 技术
- [ ] 1080×1920（或 1080×1440）、30fps、H.264 yuv420p、AAC 48k、faststart —— `xhs_export.py` 的自检全 PASS
- [ ] 时长 20–45 秒（超过 60 秒有明确理由）
- [ ] 响度归一过，开头没有爆音，结尾没有突然截断
- [ ] 逐帧看过 0–3 秒和最后 2 秒，没有黑场、没有半截字

## 配音与字幕
- [ ] 全片是同一个女声普通话 AI 配音（`voiceover.py`），引擎用的是 `doctor.py` 报告的最高可用档；音色与账号之前的视频一致
- [ ] `voiceover.py` 的表里没有「比分镜晚 N 秒」，没有「定格补足超过 1.5 秒」
- [ ] 戴耳机从头听一遍：价格、英文、数字没有念错（念错用 `{显示=读音}` 改）；句间有气口，结尾没被截断
- [ ] 字幕来自 `voiceover.srt`，抽 3 处（开头、中段换屏最密处、最后一屏）逐帧核对：字幕与声音同起同落，误差不超过 0.2 秒
- [ ] 字幕一句一屏 ≤ 14 字，无错别字，没有一闪而过的屏；位于安全区，不被右侧按钮列遮住，不压住画面里的关键文字
- [ ] 有 BGM 时人声始终清楚

## 内容

- [ ] 演示画面文字可读（手机上看一遍，不是电脑上）
- [ ] 价格、商品名与海报 / 商品页一致
